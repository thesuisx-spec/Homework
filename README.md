# Minna no Nihongo I — домашние задания

Домашние задания для уроков 1–25 учебника «Minna no Nihongo I», по 2 листа A4 на урок.

- `worksheets/` — исходники листов (холст Claude Design): `Sheet.dc.html` — общий шаблон, `Main.dc.html` и `LNN-P.dc.html` — данные уроков.
- `illustrations/` — векторные иллюстрации (SVG), используемые в заданиях.
