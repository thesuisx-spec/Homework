# Ukiyo-e Studio

Офлайн-программа для фильмов в стиле японской гравюры укиё-э. Вы собираете фильм из видов Токио,
пишете свои надписи и субтитры, выбираете время суток и сохраняете MP4 со звуком.
Интернет, сервер и нейросеть не нужны: всё рисуется, озвучивается и кодируется на вашем компьютере.

## Что умеет

- **Виды:** залив (рассвет, день, ночь), сакура у реки (день, ночь), ливень на перекрёстке Сибуя (день, ночь),
  фонарь Асакусы (день, ночь). Порядок и длительность любые, от 3 до 30 секунд на сцену.
- **Тексты:** японская надпись на табличке каждой гравюры, субтитр внизу кадра, название серии,
  финальная табличка и строка.
- **Альтернативный оттиск:** если подряд стоят две сцены одного вида с разным временем суток, вторая
  печатается заново поверх тех же линий, как у мастеров Эдо.
- **Путник** в соломенной шляпе проходит через все виды. Его можно выключить.
- **Музыка** сочиняется под ваш фильм: сямисэн, кото, сякухати, тайко, храмовый колокол. Сэмплов нет, всё синтезируется.
- **Экспорт в MP4:** H.264, 1080p или 720p, 24 кадра в секунду. Звук AAC (на Windows и Mac) или Opus.
- **Проекты** сохраняются в файлы `.ukiyoe` и открываются снова.

## Как получить программу

**Готовая сборка.** Откройте раздел **Releases** репозитория на GitHub и скачайте файл для своей системы:

- **Windows:** `UkiyoeStudio-Setup-1.0.2.exe` — обычный установщик с ярлыками на рабочем столе и в меню «Пуск».
  Программа не подписана сертификатом, поэтому Windows может показать окно «Система Windows защитила ваш компьютер».
  Нажмите **«Подробнее» → «Выполнить в любом случае»**. Без установки можно запустить `UkiyoeStudio-Portable-1.0.2.exe`;
- **macOS:** `.dmg`. В первый раз запускайте программу правой кнопкой мыши → «Открыть»;
- **Linux:** `.AppImage`. Перед запуском выполните `chmod +x`.

**Сборка самому** (нужен Node.js 22+, интернет только на время установки):

```bash
cd ukiyoe-studio
npm ci
npm start              # запустить без сборки
npm run dist:win       # Windows: установщик dist/UkiyoeStudio-Setup-*.exe и портативный exe
npm run dist:mac       # macOS (собирается только на Mac)
npm run dist:linux     # Linux: dist/*.AppImage
```

## Как устроено

| Файл | Что делает |
|---|---|
| `main.js`, `preload.js` | окно Electron, диалоги сохранения; запросы в сеть запрещены |
| `renderer/engine/print.js` | печать: бумага васи, древесина, барэн, бокаси, печати |
| `renderer/engine/views.js` | гравюры и их варианты по времени суток |
| `renderer/engine/traveler.js` | путник |
| `renderer/engine/film.js` | фильм из описания: камера одним дублем, таблички, субтитры, финал |
| `renderer/engine/audio.js` | партитура из описания фильма (Web Audio) |
| `renderer/export.js` | кодирование MP4 (WebCodecs и mp4-muxer) |
| `renderer/editor.js` | интерфейс редактора |

Проверка экспорта без интерфейса: `electron . --selftest out.mp4`. Команда соберёт фильм по умолчанию в 720p и закроется.
